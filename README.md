# strata

A local-first Markdown viewer and editor for Windows. Read, search, and keep an index of your own notes, entirely on your machine.

More at [insanitiks.com](https://insanitiks.com).

## Free and Pro

Viewing, searching, indexing individual files and watching folders are free.

strata Pro is a subscription that adds:

- **Editing** — create and edit Markdown, with the preview side by side.
- **MCP server** — let AI clients such as Claude Desktop search and read the Markdown files strata manages.

Pro comes with a 14-day free trial. Buy Pro, enter your license key, or manage your subscription in the plan dialog, which opens from the settings panel or the badge in the activity bar.

## Download

Windows only. Get the installer from [Releases](https://github.com/insanitiks/strata/releases/latest).

## The installer is unsigned

strata is not code-signed, so Windows does not recognise the publisher. Running the installer brings up a Microsoft Defender SmartScreen dialog titled **"Windows protected your PC"**, which at first offers only a "Don't run" button.

To continue, click **More info**, then **Run anyway**.

This is what Windows shows for any installer without a code-signing certificate and without an established reputation. It is not a detection of anything in the file. Updates that strata installs itself do not go through this dialog.
